* Explain how vacuum systems work in semiconductor equipment and how you would diagnose poor base pressure 
 * Vacuum systems remove gas molecules so processes like etch,deposition, and implant can run in a controlled environment.
   * To diagnose poor base pressure, I first check the gauge health, pump status, 
   * We can the conduct a rate of rise test to help separate real leaks from out gassing
   * Next would be checking O-ring seals, chamber hardware, an recent maintenance points 
   * Valve sequencing

* What is preventive maintenance, and how do you decide the right PM interval for a tool
 * Preventive maintenance is scheduled work that prevents predictable degradation before it becomes unplanned downtime 
   * The OEM interval is a good starting point 
     * Then adjustment based on chamber hours, wafer count, fault history, and FDC/particle data 
 * The goal based of all this data is to maximize availability
