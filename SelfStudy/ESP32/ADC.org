#+title: ADC esp32 C Notes

* General Things To Note
+ The maximum resolution of the ADC provided by the ESP32 is 12 bits
  * So the measured voltage is between 0 and 4095
  * You can change the resolution or bit-width

* ESP Layout
+ two modes for ADC conversion. One shot mode and Continuous mode
+ Pins 3 through 15 and 23 to 26 can be used for ADC 3 being 0 and 15 being 14
** One Shot Mode
+ The ADC conversion only happens when instructed.
  * So every time you want to get the output you have to call the function
** Continuous  Mode
+ The ADC Conversion is repeated automatically at a rate defined by you

* Libraries
+ This is for oneshot mode
#+begin_src C
