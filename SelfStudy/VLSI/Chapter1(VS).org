#+title: CMOS Logic(Chapter 1)
* CMOS Transistors
-> Similar to BJT's in their function CMOS transistors work as electronic
switches
-> They differ from BJT's in the fact that they are *Voltage Controlled*
instead of current controlled like BJT's
-> Because of this they typically have very high input impedance
-> This high input impedance is achieved by using a oxide layer (SiO₂) at the gate
-> There are two main types of CMOS transistors
** Terminals
-> CMOS transistors have three terminals the drain(D), Source(S), Gate(G)
*Gate* -  The control input
*Source* - Provides the current
*Drain* - Where current flows once activated
** pMOS
-> For pMOS transistors the body is held at a positive voltage
-> This means when the gate is also at a positive voltage, the source and drain junctions are
reverse-biased and no current flows and the transistor is OFF
** nMOS
-> For nMOS transistors the body is grounded
-> So when the gate is also at a positive voltage, the source and drain are also reverse-biased
so the transistor is ON
*** Both
-> So we typically use both transistors in CMOS logic with a *pull up network* and a
*pull down network*
-> We do this because pMOS transistors are great for representing a logic of 0 so off
and nMOS transistors are great for representing a logic of 1 so on
-> If we use a combination of both it allows to represent multiple logic
