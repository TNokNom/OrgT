 * *Channel Length Modulation* is the phenomenon that occurs with changes in \(V_{DS}\)
 + When a voltage \(V_{DS}\) is applied to a *FET* the depletion region expands and subsequently shortens the
    channel length
 + During this the gate voltage has less of an impact on the change in \(I_{DS}\) as the FET approaches
    the *breakdown region*
 + The parameter \(\lambda\) is known as the channel length modulation parameter
 + So we now get the following equation for the drain current in saturation =>
 \[
     I_D = \frac{1}{2} \mu_n C_{ox} \frac{W}{L} (V_{GS} - V_{th})^2 (1 + \lambda V_{DS})
     \]

* Differential Amplifier Input Decomposition

** Inputs
+ Two inputs: \( V_{in1} \) and \( V_{in2} \).
 * Each input can be expressed as a sum of:
  - A *common-mode* component (\( V_{CM} \))
  - A *differential* component (\( V_{id} \))

** Definitions
+ Common-mode voltage:
  \[
  V_{CM} = \frac{V_{in1} + V_{in2}}{2}
  \]

+ Differential voltage:
  \[
  V_{id} = V_{in1} - V_{in2}
  \]

** Input Expressions
+ Each input can be written as:
  \[
  V_{in1} = V_{CM} + \frac{V_{id}}{2}
  \]

  \[
  V_{in2} = V_{CM} - \frac{V_{id}}{2}
  \]

** Why This is Useful
+ Separates the signal into:
  - *Common-mode part*: response when both inputs move together
  - *Differential part*: response when inputs move in opposite directions
- Allows calculation of:
  - *Differential gain*
  - *Common-mode gain*
** Example

If \( V_{in1} = 1.1 \, \text{V} \) and \( V_{in2} = 0.9 \, \text{V} \):

- \( V_{CM} = \frac{1.1 + 0.9}{2} = 1.0 \, \text{V} \)

- \( V_{id} = 1.1 - 0.9 = 0.2 \, \text{V} \)

- Thus:
  \[
  V_{in1} = 1.0 + 0.1 \quad , \quad V_{in2} = 1.0 - 0.1
  \]

* Cascode Gain Stage

+ This configuration is typically used for its high gain for a single stage
  * This is due to the large impedance at the output 
  * In order to utilize this high gain, current sources are connected to the output nodes 
    * This can be something like a common gate setup 
  * The main drawback is we lose some of the output voltage range compared to that of the 
     common-source amplifier
      * This is because we need more of that voltage to keep the transistors in the active region 
   
+ The second reason for their use is tat they limit the voltage across the input drive transistor 
  * This helps minimize any short-channel effects 
    * Also permits the circuit to handle higher output voltages without risking damage 
+ It typically comes in two configurations 
  * (*a*) telescopic-cascode amplifier 
  * (*b*) folded-cascode amplifier 
+ The folded cascode provides greater output swing
  * But it consumes more power due to drain having to bias currents for *Q1* & *Q2*
    which are drawn in parallel from the supply voltage   
+ While the telescopic cascode share the same dc drain current
