* Class A Transistor Amplifiers
:PROPERTIES:
:ID:       98110679-4cda-4db9-aea9-104d86b032f3
:END:
[[file:../../../../MacShots/Class_A_Transistor_Amplifiers/2025-05-18_12-07-36_screenshot.png]]
 * This is a class A transistor amplifier
 * Its max theoretical efficiency is 25% => We can calculate it using the formula \(n =\frac{P_{L}}{P_{DC}} \cdot 100 \)
 - n being the efficiency PL being the ac lower power PDC being the power delivered by the dc power source
 * conducts for 360 degrees of the input cycle
 * In order to maximize efficiency for this circuit we set => \(V_{CE} = \frac{1}{2} V_{cc} \)
** Advantages
 * conducts for 360 degrees of the input cycle
 * Has very little to no distortion
*** Improvements
 * In order to improve efficiency for this circuit we can replace
   RC with a transformer that contains a load resistor
 * The output is the second part of the transformer
 * The maximum theoretical efficiency improves to 50 percent
