* BJT'S
** Common Emitter
 * Configuration where the emitter terminal is common to both the input and output
 * Good voltage gain and phase inversion (180 degrees)
** Common Collector
 * Also known as emitter follower
 * The collector terminal is common to both input and output
 * Input is applied to the base
 * Output voltage is read from the emitter
*** Characteristics
 * High current gain
 * Low output impedance
** Common Base
 * Base terminal is common to both input and output
 * Input is applied to the emitter
 * Output is read from the collector
* Fet's
** Source Follower
 * Input is applied to the Gate
 * Output is read at the source
*** Characteristics
 * High input impedance
 * Follows the input voltage
 * Low output impedance

\[
\frac{V_{out}}{r_{o}||R_{D}} = -g_{m}v_{in} \rightarrow \frac{V_{out}}{v_{in}} = -gm(r_{o}||R_{D})
\]
 + From this equation we know that in order to maximize gain we should be looking at \(g_{m}\) and
   or \(R_{D}\)
**** Finding the output resistance
+ In order to find the output resistance we inject a test voltage into \(v_{out}\) and measure the
   voltage and current through it
  * We also ground the gate terminal
+ We are left with \(R_{out} = r_{o}||R_{L}\)
*** Diode Connected  Common Source
+ For this circuit we replace the resistor with a diode connected transistor load
  * we do this by shorting the gate and drain together
+ Due to the short the gate voltage is always equal to the drain voltage
   * therefore the mosfet is always in saturation when current is flowing
     -> \(v_{ds} = v_{gs}\)
+ Calculating the output resistance we get
   * assuming we connect a test voltage to the drain of transistor
   \(R_{out} = g_{m}v_{th} + \frac{v_{th}}{r_{o}} = i_{t} \rightarrow \frac{v_{th}}{i_{t}} = \frac{1}{g_{m}}||r_{o} = \frac{1}{g_{m}}\)

**** Important Note
+ its important to note the difference between (*gm*) and (*gmb*)
  * (*gm*) is the Transconductance and it is how much the drain current changes with gate voltage
    * (*gmb*) is the Body Transconductance and it is how much drain current changes with the body source voltage due to the body effect


** Common Gate
 * Input is the source terminal
 * Output is read at the drain terminal
*** Characteristics
 * Low input impedance
 * No voltage gain
 * Used in rf applications
