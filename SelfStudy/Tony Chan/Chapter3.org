[[file:../../../MacShots/Source_Follower_Or_Common_Drain_Amplifier/2025-08-05_01-40-34_screenshot.png]]
+ Before we talk about this circuit, we must describe what a *voltage buffer* is
  * A voltage buffer is a circuit that outputs the same voltage as it receives as the input
  * The thing that makes it so special is -> It isolates the source from the load
  * It becomes a voltage controlled current source i.e *High input impedance* , *Low output impedance*
  * It can protect the signal and prevents distortion
+ Now for the circuit above Q2 the current mirror is an active load that supplies the bias current for Q1
  * This gain for this circuit is unity which is < 1. This is due to the fact that this circuit isn't needed for voltage gain
     it's there to help drive loads
** Circuit Analysis
+ For this circuit the body effect comes into play
   * The source isn't held at small signal ground
