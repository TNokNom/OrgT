* Cascade Current Mirrors
 * A cascade device can shield a current source, reducing the voltage variations across it
 * *Channel Length Modulation* is the phenomenon that occurs with changes in \(V_{DS}\)
 + When a voltage \(V_{DS}\) is applied to a *FET* the depletion region expands and subsequently shortens the
    channel length
 + During this the gate voltage has less of an impact on the change in \(I_{DS}\) as the FET approaches
    the *breakdown region*
 + The parameter \(\lambda\) is known as the channel length modulation parameter
 + So we now get the following equation for the drain current in saturation =>
 \[
     I_D = \frac{1}{2} \mu_n C_{ox} \frac{W}{L} (V_{GS} - V_{th})^2 (1 + \lambda V_{DS})
     \]

* Differential Amplifier Input Decomposition

** Inputs
+ Two inputs: \( V_{in1} \) and \( V_{in2} \).
 * Each input can be expressed as a sum of:
  - A *common-mode* component (\( V_{CM} \))
  - A *differential* component (\( V_{id} \))

** Definitions
+ Common-mode voltage:
  \[
  V_{CM} = \frac{V_{in1} + V_{in2}}{2}
  \]

+ Differential voltage:
  \[
  V_{id} = V_{in1} - V_{in2}
  \]

** Input Expressions
+ Each input can be written as:
  \[
  V_{in1} = V_{CM} + \frac{V_{id}}{2}
  \]

  \[
  V_{in2} = V_{CM} - \frac{V_{id}}{2}
  \]

** Why This is Useful
+ Separates the signal into:
  - *Common-mode part*: response when both inputs move together
  - *Differential part*: response when inputs move in opposite directions
- Allows calculation of:
  - *Differential gain*
  - *Common-mode gain*
** Example

If \( V_{in1} = 1.1 \, \text{V} \) and \( V_{in2} = 0.9 \, \text{V} \):

- \( V_{CM} = \frac{1.1 + 0.9}{2} = 1.0 \, \text{V} \)

- \( V_{id} = 1.1 - 0.9 = 0.2 \, \text{V} \)

- Thus:
  \[
  V_{in1} = 1.0 + 0.1 \quad , \quad V_{in2} = 1.0 - 0.1
  \]
