*** SIMD
-> *SIMD* stands for Single Instruction Multiple Threads
- It allows multiple threads to execute the same instruction but
  on different data

*** Memory Hierarchy
  -> Global Memory: Large but slower, used for all data storage.
  -> Shared Memory: Faster and shared among threads within the same block.
  -> Registers: Fastest local storage for individual threads.

** Streaming Multiprocessors {*SMs*}
  Groups of CUDA cores that manage thread execution and scheduling.

* GPU Architecture Types
** NVIDIA Architecture
  -> Fermi, Kepler, Maxwell, Pascal, Volta, Turing, Ampere, and Ada Lovelace.
  
** AMD Architecture
  -> GCN (Graphics Core Next) and RDNA (Radeon DNA).

* Parallel Processing
GPUs excel in parallel processing due to their high number of cores. They are ideal for tasks like:
  -> Image processing
  -> Machine learning and AI
  -> Scientific simulations
