* Lossy & Lossless
+ Data compression is the process of encoding digital information using fewer bits than the original file size
  * It allows for more efficient storage and faster transmission over networks
+ Lossy and Lossless ar both types of data compression
** Lossless
+ Losless reduces a file size by removing any unnecessary metadata
  * The file data is restored and rebuilt in its original form after decompression
    * No data is lost during this and it's reversible
** Lossy
+ Lossy reduces a file size by permanently removing some of the original data
  * Its typically only used when you can afford to lose some data or
    if the storage spaces needs to be freed up
  * It uses an algorithm to decides the bits they aren't necessary or less important
