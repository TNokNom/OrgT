* Instruction Suffix: S {*Set Condition Flag*}
- For instructions we can add a suffix *S* in order to update
  the N,Z,C,V flags in APSR register
** EX:
start:
LDR r0, = 0xFFFFFFF
LDR r1, = 0x000000001
ADD *S* r0, r0,r1
stop:
B stop
** Ex: {*64 bit addition*}
- A register can only store 32 bits
- A 64-bit integer needs two register
- Split 64-bit addition into two 32-bit additions
